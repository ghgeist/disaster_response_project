2026-01-29 — UI Prototyping Strategy: Make → Vendor → Execute

Explored a bidirectional AI workflow between Cursor and Figma Make to rapidly prototype a dashboard UI. The loop proved effective for fast ideation and layout generation.

Investigated Figma MCP integration to support direct, structured access to Make files from Cursor. Discovered that Make MCP access is intentionally anchor-based and non-enumerable, which complicates full bidirectional synchronization.

Chose to prioritize execution speed over tooling completeness by exporting the Make output as code, vendoring it into the repo as a reference artifact, and proceeding one-way. This blocks live round-trip updates but preserves design intent while unblocking backend and API work.

This decision is explicit, reversible, and scoped to the current build phase.
